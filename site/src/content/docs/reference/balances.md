---
title: Opening and closing balances
description: Per-account, per-year journals included before and after the imported transactions.
---

`hledger-flow init` gives the example account editable opening and closing
balance journals with commented examples. Both files are optional. Import
adds the balance files that exist when it generates that year's account
include. Use a [manual journal](/reference/manual-journals/) for other entries in the
account, such as a missing fee or a balance assertion.

## Opening Balances

If an account already held money before your first statement, record that
amount in `<year>-opening.journal` in the account folder. For example,
`import/john/mybank/savings/2018-opening.journal` is included before that
account’s 2018 statement journals. Use the balance just before the first
imported transaction. In the combined ledger, the balance carries forward
into later years.

An opening balance may look something like this:

    2018-06-01 Savings Account Opening Balance
        assets:mybank:savings               $102.01
        equity:opening-closing

## A Note of Caution Regarding Closing Balances

When closing your balances it may result in some `hledger` queries showing zero-values, or there could be issues with balance assertions.

The hledger manual explains [how closing transactions affect balance assertions](https://hledger.org/hledger.html#close-and-balance-assertions).

Some of the gotchas you may run into are also described in [this hledger-flow issue](https://github.com/apauley/hledger-flow/issues/79).

## Closing Balances

Similar to opening balances, `hledger-flow` looks for an optional file
named `YEAR-closing.journal` in each account directory. Example:
`import/john/mybank/savings/1983-closing.journal`

The yearly account include places this file after the statement journals
and the optional account-level `post-import.journal`. Use a closing entry
when you deliberately want to bring the account balance to zero. A balance
otherwise carries forward into later years.

A closing balance may look something like this:

    2018-06-01 Savings Account Closing Balance
        assets:mybank:savings               $-234.56 = $0.00
        equity:opening-closing

## Example Opening and Closing Journal Files

As an example, assuming that the relevant year is `2019` and
`hledger-flow` is about to generate
`import/john/mybank/savings/2019-include.journal`, then one or both of
the following files will be added to the include file if they exist:

1.  `import/john/mybank/savings/2019-opening.journal`
2.  `import/john/mybank/savings/2019-closing.journal`

The account's pre-import journal comes first, followed by the opening file
and imported statements. The post-import journal comes next, followed by the
closing file. Entries still carry their own dates. This order matters for
assertions against other postings on the same day.

An include file may look like this:

``` bash
cat import/john/mybank/savings/2019-include.journal
```

    ### Generated by hledger-flow - DO NOT EDIT ###

    include _manual_/2019/pre-import.journal
    include 2019-opening.journal
    include 3-journal/2019/123456789_2019-01-30.journal
    include _manual_/2019/post-import.journal
    include 2019-closing.journal

## Stability

Closing balances sometimes result in [unexpected query results](https://github.com/apauley/hledger-flow/issues/79).
In future we may change how/where the generated files include the closing journal.

We may also need to suggest some naming conventions for opening and closing balances so that reports can exclude
some of these transactions.

It is also possible that we might want to change the name/location of the closing journal,
but we'll try to avoid this if possible, because that would require users to rename their existing files.
