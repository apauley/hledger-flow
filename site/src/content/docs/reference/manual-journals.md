---
title: Manual journals
description: Where to keep transactions and balance assertions that come from outside your statements.
---

Use a manual journal to record an entry you have to supply yourself. Choose
the most specific folder that covers the accounts involved and record each
entry once. Use the year of the entry in the path.

| Level | Folder | Example |
| --- | --- | --- |
| Account | `import/<owner>/<bank>/<account>/_manual_/<year>/` | Fill a gap in a checking statement with a missing debit card fee, or assert the balance from your bank's website when the CSV has no balance column. |
| Bank | `import/<owner>/<bank>/_manual_/<year>/` | Record a transfer between checking and savings at the same bank that is missing from both exports. |
| Owner | `import/<owner>/_manual_/<year>/` | Record a transfer between one person's savings at one bank and checking at another. |
| Ledger | `import/_manual_/<year>/` | Record a reimbursement between you and another owner for a shared household expense. |

An account-level entry should concern that account. Its other posting can
name an expense or another counter-account. For example, after the last
imported entry for a day, you can assert the checking balance without
changing it:

```hledger
2026-01-31 Check against online banking
    assets:mybank:checking  0 USD = 975.00 USD
```

Use the dedicated [opening and closing balance files](/reference/balances/)
in the account folder to establish or close out its balance.

## Before or after the imported entries

At any of the four levels, create `pre-import.journal`, `post-import.journal`, or
both. Import omits absent files from the include files it maintains. The
filenames control where the generated yearly include places the entries.
`pre-import.journal` appears before the imported statement
journals or child folders' yearly includes at that level.
`post-import.journal` appears after them. Actual transaction dates come
from the journal entries. If you assert the balance after another posting
to the same account on the same date, place the assertion after it in
the include order.

For example, the generated `import/john/2026-include.journal` can include
both of John's bank folders between his pre- and post-import journals:

```hledger
### Generated by hledger-flow - DO NOT EDIT ###

include _manual_/2026/pre-import.journal
include mybank/2026-include.journal
include otherbank/2026-include.journal
include _manual_/2026/post-import.journal
```

At account level `pre-import.journal` comes before the optional opening
file and `post-import.journal` comes before the optional closing file. See the
[account include example](/reference/balances/#example-opening-and-closing-journal-files).

## Include manual entries in reports

Run `hledger-flow import` so hledger-flow discovers the manual
files. Either file establishes that year's include files, even for a ledger
with no statements. Run `hledger-flow report` to update the reports.

An entry in an account, bank or owner journal appears in that owner's
reports and in the aggregate reports. Entries in `import/_manual_/<year>/`
appear in the aggregate reports under `reports/all/<year>/`. If an owner is
named `all` in any letter case, the aggregate reports go under
`reports/_all_/<year>/`.

`hledger-flow init` supplies commented examples at all four levels.
Edit these files yourself and use `hledger-flow import --verbose` to see
the paths import checks.
